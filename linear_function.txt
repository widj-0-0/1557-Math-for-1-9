Линейная функция, её свойства и график

Нам известно, что одним из способов задания функции является аналитический способ, то есть с помощью формулы. Исследуем функцию, которая задаётся формулой y = kx + b. Она называется линейной функцией. Выясним, как выглядит её график и какими свойствами она обладает.

Определение: Функция вида y = kx + b, где x - независимая переменная, k и b — любые действительные числа, называется линейной функцией.

При k ≠ 0 и b = 0 линейная функция y = kx + b принимает вид y = kx, то есть является прямой пропорциональностью.
Таким образом, прямая пропорциональность является частным случаем линейной функции.
В курсе геометрии 9 класса будет показано, что графиком линейной функции является прямая. Для построения прямой в декартовой системе координат достаточно найти координаты двух точек графика. 

Перечислим свойства функции y = kx + b на примере функции y = 2x - 4:
1) Область определения функции	D(y): (-∞; +∞)
2) Область значений функции E(y): (-∞; +∞)
3) Наибольшее, наименьшее значения функции определить невозможно
4) Нули функции: y = 0 при x = 2
5) Промежутки возрастания, убывания функции: y⭡ на всей области определения

-Заметим, что если x = 0 , то  y = k*0 + b = b, то есть график линейной функции проходит через точку (0;b) . Другими словами,  b "отвечает" за пересечение прямой с осью Oy .

Если  b > 0, то прямая пересекает ось  Oy выше нуля.
Если  b < 0, то прямая пересекает ось  Oy ниже нуля.
Если  b = 0, то прямая проходит через начало координат.

-За возрастание или убывание линейной функции "отвечает" коэффициент , который ещё называют угловым коэффициентом.

Если k > 0 , то линейная функция возрастает.
Если  k < 0, то линейная функция убывает.
Если  k = 0, то прямая будет параллельна оси Ox .

Иными словами, для линейной функции  y = kx + b графиком является прямая, проходящая через точку  (0;b). Функция возрастает на всей области определения, если k > 0 , функция убывает на всей области определения, если k < 0. Функция параллельна оси абсцисс, если k = 0
