Линейные уравнения - уравнения с одним неизвестным, где неизвестное (обычно x) стоит в первой степени, а решаются они через обратные арифметические действия (нахождение неизвестного компонента сложения/вычитания/умножения/деления). Основные принципы: корень – это число, при подстановке которого равенство становится верным; решение — это поиск этого числа с помощью преобразования уравнения (перенос членов с изменением знака, приведение подобных) до вида ax=b, а затем деление b на a, чтобы найти x. 
Основные понятия
Уравнение: Равенство, содержащее неизвестное число (переменную), например, x+5=12.
Корень уравнения: Значение переменной, которое превращает уравнение в верное числовое равенство.
Для x+5=12, корень – это 7 (так как 7+5=12).
Решить уравнение: Найти все его корни. 
Алгоритм решения (на примере 2x+4=10) 
Найти неизвестное слагаемое/множитель:
Для 2x+4=10: 2x – это неизвестное слагаемое.
2x=10-4 <=> 2x=6.
Для x * 3 = 15: x – неизвестный множитель.
x=15:3 <=> x=5.
Найти неизвестную переменную:
Разделить известное число (6) на коэффициент при переменной (2): x=6:2 <=> x=3.
Проверка: 
Подставить найденный корень обратно в уравнение, чтобы убедиться, что равенство верное. Для 2x + 4 = 10: 2 * 3 + 4 = 6 + 4 = 10. Верно.
