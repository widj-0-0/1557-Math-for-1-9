Что такое арифметическая прогрессия?
Пусть последовательность {xₙ} такова, что её первый член равен a, а каждый следующий член отличается от предыдущего на одно и то же число d, иными словами,
⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀x₁ = a₁⠀⠀⠀⠀xₙ₊₁ = xₙ + d,
тогда такая последовательность называется арифметической прогрессией. Число d называется разностью (или шагом) прогрессии. 

Пример: 1,3,5,7,..  — арифметическая прогрессия c разностью d = 2.


Какая формула общего члена арифметической прогрессии?
Найдём первые несколько членов арифметической прогрессии:
⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀x₁ = a₁,⠀⠀x₂ = x₁ + d = a + d,⠀⠀⠀x₃ = x₂ + d = a + 2d,⠀⠀⠀x₄ = x₃ + d = a + 3d
и т. д. Нетрудно убедиться, что формула общего члена арифметической прогрессии выглядит следующим образом:
⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀xₙ = a + d(n - 1)

Формула суммы первых n членов арифметической прогрессии:
⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀Sₙ =⠀⠀ x₁ + xₙ⠀⠀⠀⠀= ⠀⠀2a + d(n - 1)

Характеристическое свойство арифметической прогрессии
Последовательность {xₙ} является арифметической прогрессией тогда и только тогда, когда для любого натурального k имеет место равенство
⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀⠀xₖ ₊ ₁ = ⠀ xₖ + xₖ ₊ ₂
